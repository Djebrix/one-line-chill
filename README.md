A single sentence of horror, written to frighten a reader in one breath — for the [make.fun bounty](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488).

> My dead grandmother's voicemail said the man in our attic has finally learned to sound like me.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (one line, 95 characters) to `$ENTRY_OUTPUT_DIR` (defaults to `/output`).
